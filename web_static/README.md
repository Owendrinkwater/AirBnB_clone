# Web Static

This project is part of the ALX Higher Level Programming curriculum. Its goal is to introduce the fundamentals of front-end web development using **HTML** and **CSS**.

## Description

In this project, we build static web pages step by step as a foundation for the front-end of the AirBnB clone. The project is purely static:
- No JavaScript
- No dynamic data loading
- No external assets

We focus on mastering HTML structure and CSS styling, while adhering to the ALX style guide and W3C compliance.

## Project Requirements

- Use of `vi`, `vim`, or `emacs` editors
- All files must end with a new line
- `README.md` file is mandatory
- All CSS code must be in the `styles/` folder
- All image assets must be in the `images/` folder
- No use of:
  - `!important` in CSS
  - `id` selectors in CSS
  - `<img>`, `<iframe>`, or `<embed>` HTML tags
  - JavaScript
- Code must validate with the [W3C Validator](https://validator.w3.org/)

## Learning Objectives

By completing this project, you should be able to explain:

- What HTML is and how to create HTML pages
- What a markup language is
- How the DOM (Document Object Model) works
- HTML elements, tags, and attributes
- What CSS is and how to style HTML elements
- How CSS selectors and specificity work
- The box model and layout techniques in CSS
- How browsers render HTML and CSS
